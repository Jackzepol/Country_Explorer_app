Country Explorer
Aplicación web desarrollada con React, Redux Toolkit y Axios para consultar información de países y ciudades usando una API pública.

Tecnologías
React
React Router
Redux Toolkit
Axios
Vitest
React Testing Library
SASS Modules
Styled Components
Funcionalidades
Búsqueda de países
Vista de detalle
Gestión de favoritos
Consumo de API externa
Testing
Diseño responsive
Instalación
npm install

Desarrollo
npm run dev

Testing
npm test

Producción
npm run build
